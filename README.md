# Ideabrowser plugin for Cursor & Grok Bot

Connect your AI tools to [Ideabrowser](https://www.ideabrowser.com) — the AI-powered platform for finding, researching, and building startup ideas.

## What you get

Once connected, your agent can:

- **Browse & filter 1,000+ researched startup ideas** — by category, opportunity score, or a natural-language ask.
- **Get the Idea of the Day** — a fully researched business idea, every day.
- **Explore trends & markets** — curated trending keywords, growing markets, and pre-researched market insights.
- **Get personalized recommendations** — ideas matched to your skills, budget, and goals.
- **Run custom research** — trend research, market insight reports, and full idea analysis pipelines on any topic (Pro).
- **Build with 40+ pre-made agents** — landing pages, pricing, funnels, positioning, and more (Pro).

## Install

**Cursor:** install the Ideabrowser plugin from the Marketplace, then sign in when prompted.

**Grok Bot:** find Ideabrowser in Settings → Plugins, or tell your bot:

```
Add this MCP server: https://www.ideabrowser.com/api/mcp/mcp
```

Tap the sign-in card, approve access on ideabrowser.com, and you're connected.

**Any other MCP client:** add the server URL `https://www.ideabrowser.com/api/mcp/mcp` and complete the OAuth sign-in, or create an API key at [ideabrowser.com/hub/build/connectors](https://www.ideabrowser.com/hub/build/connectors) and append it as `?key=YOUR_API_KEY`.

## Authentication

The plugin uses OAuth: you approve access in your browser and the connection is tied to your Ideabrowser account. No API keys to copy. You can review and revoke access anytime at [ideabrowser.com/hub/build/connectors](https://www.ideabrowser.com/hub/build/connectors).

An Ideabrowser account is required — [start free](https://www.ideabrowser.com).
